# TecGate: name, mark and wordmark

**The mark is excluded from the software licence.** A wordmark is a trademark, not software. Released with the
documentation and example files, anyone could put it on a product of their own — and that is exactly what a trademark
exists to prevent.

This file applies to:

| File | What it is |
|---|---|
| `marke/logo-wortmarke-hell.svg` | the “TecGate” wordmark, dark lettering — for light backgrounds |
| `marke/logo-wortmarke-dunkel.svg` | the same wordmark, light lettering — for dark backgrounds |
| the mark inside the running interface | the same mark without the lettering, as favicon, app icon and header mark — it ships in the container image, not in this repository |

And to the **name “TecGate”** itself.

---

## What is permitted

- **Passing them on unchanged in order to refer to TecGate.** In an article, a
  tutorial, a list of tools, a talk, a screenshot of the running interface.
- **Saying that your own software uses TecGate** or works with it — “for
  TecGate”, “works with TecGate”.
- **Scaling them** and placing them on a background that preserves the
  contrast. The dark version is the one for dark backgrounds; the mark itself
  switches on its own via `prefers-color-scheme`.

## What is not permitted

- **Using them as your own mark** — as the logo of another product, a service,
  a company or an account.
- **Using them for a derived product.** The result of a derived or repackaged
  build is not called TecGate and does not carry this mark. **That is not a
  restriction on the work, it is the separation of the work from the
  attribution:** whoever took the mark along would be passing off someone
  else's work as their own — or their own as someone else's.
- **Altering them** — colours, aspect ratio, stroke width, spacing, an
  additional word beside them in the same lettering.
- **Using them in a way that claims an endorsement, a partnership or an origin**
  that does not exist.

## Why this is here although the documentation is free to copy

The documentation and the example files in this repository may be copied and
adapted, and that is intended. A trademark has a different job: it says **where something comes
from**. Released on the same terms, a repackaged version could appear under the
same name and mark, and nobody could tell the two apart. That does not harm the
author, it harms the reader.

This is why the same statement stands in three places: here, in `LICENSE`, and
in the README — **a licence file nobody opens protects nothing.**

If in doubt, or for a use not covered here: ask.
